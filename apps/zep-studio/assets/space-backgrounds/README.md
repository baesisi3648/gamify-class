# 우주기지 배경 예시

ZEP 맵 공방의 `아랫배경` 레이어에 바로 적용할 수 있는 3:2 PNG 예시입니다.

- `space-corridor.png`: 우주기지 복도
- `space-stair-room.png`: 계단·수직 이동실
- `space-research-lab.png`: 우주 연구실
- `space-experiment-lab.png`: 생명·화학 실험실
- `space-command-center.png`: 관제실
- `space-airlock-hangar.png`: 에어록·소형 격납고

모든 예시는 캐릭터를 가리는 전경 요소와 윗배경을 제외한 배경 전용 이미지입니다.
