# 프로젝트 제네시스 자산 관리

이 폴더는 ZEP SF 방탈출 프로젝트 **프로젝트 제네시스**의 신규 배경과 목록용 미리보기를 보관합니다.

## 현재 구성

- `genesis-opening-corridor.png`: 오프닝 횡스크롤 복도 배경, 4096×1024
- `thumbs/`: 프로젝트 보드에서 사용하는 가벼운 미리보기 이미지
- 기존 6종 맵 세트의 원본은 `../space-backgrounds/`에 있으며, 각 세트는 앞배경과 윗배경으로 분리되어 있습니다.

## 새 자산 추가 순서

1. 완성 이미지를 이 폴더 또는 용도별 하위 폴더에 저장합니다.
2. `thumbs/`에 목록용 미리보기를 추가합니다.
3. `../../genesis-assets.js`에 ID, 분류, 파일 경로, 설명을 한 항목으로 등록합니다.
4. ZEP 공방에서 불러올 자산이라면 `../../app.js`에 해당 쿼리 파라미터의 불러오기 동작을 연결합니다.

ID는 오프닝 배경은 `GEN-OPEN-###`, 맵 세트는 `GEN-MAP-###`, 오브젝트는 `GEN-OBJ-###` 형식을 사용합니다.
