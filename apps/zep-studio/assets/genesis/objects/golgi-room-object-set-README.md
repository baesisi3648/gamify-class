# 골지체 방 오브젝트 세트

소포체에서 전달된 물질을 최종 가공하고, 목적지별로 분류·포장·출하하는 골지체 방 설비입니다.

## 구성

- `golgi-modification-stack.png` / `golgi-modification-stack-loop.gif`
  - 청색 입력 소낭이 층상 골지체 막을 지나 자홍·금색 완성 화물로 가공됩니다.
- `golgi-vesicle-sorting-packaging-terminal.png` / `golgi-vesicle-sorting-packaging-terminal-loop.gif`
  - 완성 물질을 검사하고 색상별 수송 소낭에 봉인해 세 방향으로 출하합니다.
- `downsized-human-biocapsule-packaging-unit.png` / `downsized-human-biocapsule-packaging-unit-loop.gif`
  - 다운사이징된 합성 인체를 비식별 생명유지 캡슐에 봉인하는 최종 비밀 설비입니다.

고정 PNG는 1024×683px, 움직이는 GIF는 256×171px·6프레임·무한 반복입니다. GIF는 ZEP의 `나의 오브젝트`에 그대로 업로드할 수 있습니다.

## 이야기 연결

핵의 설계 정보 → 리보솜의 단백질 합성 → 소포체의 접힘·가공 → 골지체의 최종 변형·분류·포장 순서로 진행됩니다. 마지막 캡슐 설비에서 연구소의 진짜 목적이 축소 인류 생산이었다는 사실이 드러납니다.
