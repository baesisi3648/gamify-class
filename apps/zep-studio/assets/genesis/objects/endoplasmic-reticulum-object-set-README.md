# 소포체 방 오브젝트 세트

프로젝트 제네시스의 핵 방 오브젝트와 같은 노후 우주 연구시설 스타일로 제작한 소포체 방 설비입니다.

## 구성

- `rough-er-protein-processing-system.png` — 거친면 소포체 단백질 가공 시스템 고정형
- `rough-er-protein-processing-system-loop.gif` — 단백질 입자가 가공 라인을 따라 이동하는 반복형
- `smooth-er-calcium-reservoir.png` — 매끈면 소포체 칼슘 이온 저장소 고정형
- `smooth-er-calcium-reservoir-loop.gif` — 칼슘 이온이 충전·방출되는 반복형

## 권장 배치

- 거친면 소포체 설비는 방의 중심 또는 긴 벽면에 320~430px 크기로 배치합니다.
- 칼슘 저장소는 옆방이나 보조 구역에 260~360px 크기로 배치합니다.
- 고정 PNG와 움직이는 GIF 중 하나만 같은 위치에 사용합니다.
- GIF는 ZEP의 `나의 오브젝트`에 그대로 업로드하면 별도 앱 없이 반복 재생됩니다.

거친면 소포체 설비의 막 표면 도킹 노드는 리보솜을, 내부 가공 라인은 단백질 유입·접힘·품질검사·소낭 배출을 나타냅니다. 매끈면 소포체 설비의 연결된 관과 저장 탱크는 칼슘 이온의 저장과 방출을 나타냅니다.
