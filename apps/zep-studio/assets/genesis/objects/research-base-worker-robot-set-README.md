# PROJECT GENESIS 연구기지 통합 작업 로봇

연구기지의 여러 방에서 같은 기종처럼 보이도록 외형과 색을 통일한 ZEP용 투명 PNG 오브젝트 세트입니다.

- `genesis-worker-robot-idle.png`: 기본 대기
- `genesis-worker-robot-walking.png`: 순찰·이동
- `genesis-worker-robot-console.png`: 콘솔 조작
- `genesis-worker-robot-carrying.png`: 시료·화물 운반
- `genesis-worker-robot-maintenance.png`: 설비 정비
- `genesis-worker-robot-alert.png`: 경계·스캔

공통 디자인은 아이보리 장갑, 흑연색 관절, 청록색 바이저와 상태등, 작은 주황색 경고등입니다. ZEP 캐릭터와 나란히 놓았을 때 지나치게 커 보이지 않도록 약 3등신의 짧고 단단한 체형을 사용했으며, 얼굴과 표정을 없애 마스코트처럼 귀여워 보이지 않게 구성했습니다.

## 사용 방법

1. ZEP 에디터에서 오브젝트 추가를 선택합니다.
2. 필요한 PNG를 업로드합니다.
3. 캐릭터 키와 비교해 로봇 높이를 캐릭터의 약 1.0~1.2배로 조정합니다.
4. 콘솔·화물·정비 패널이 있는 자세는 관련 장치 가까이에 배치합니다.

모든 파일은 투명 배경이며 긴 변이 1024px를 넘지 않도록 정리되어 있습니다.
