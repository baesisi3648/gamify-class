# PROJECT GENESIS 세포 골격 방 오브젝트 세트

세포 골격을 우주 연구실의 운송·수축·구조 보강 시스템으로 해석한 ZEP 오브젝트입니다.

## 구성

- `cytoskeleton-microtubule-cargo-highway.png` / `-loop.gif`
  - 속이 빈 굵은 튜불린 관과 키네신형 운반 로봇이 소낭 화물을 옮기는 미세소관 운송로입니다.
- `cytoskeleton-actin-contraction-rig.png` / `-loop.gif`
  - 얇은 액틴 이중 나선과 미오신형 클램프가 수축·세포 운동을 만드는 미세섬유 장치입니다.
- `cytoskeleton-intermediate-filament-scaffold.png` / `-loop.gif`
  - 밧줄처럼 꼬인 섬유와 충격 흡수 지지대가 핵과 세포 구조를 보호하는 중간섬유 프레임입니다.

## ZEP 사용

- 고정 PNG: 긴 변 1024px 이하, 투명 배경
- 움직이는 GIF: 256×171, 6프레임, 무한 반복
- ZEP 에디터의 `나의 오브젝트`에 PNG 또는 GIF를 그대로 업로드합니다.

## 수업 연결

- 미세소관: 세 종류 중 가장 굵고 속이 빈 관, 소기관·소낭 수송의 레일
- 미세섬유: 가장 가는 액틴 섬유, 세포 피질·수축·운동
- 중간섬유: 밧줄형 보강재, 기계적 강도와 구조 안정성
