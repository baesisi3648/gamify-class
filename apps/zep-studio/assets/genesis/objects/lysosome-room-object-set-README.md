# PROJECT GENESIS 라이소솜 방 오브젝트 세트

라이소솜을 우주 연구실의 밀폐형 폐기물 분해·재활용 공장으로 해석한 ZEP 오브젝트입니다.

## 구성

- `lysosome-acidic-digestion-reactor.png` / `-loop.gif`
  - 산성 효소 반응로에서 불량 합성 물질을 작은 분자로 분해하고 재생 원료를 회수합니다.
- `synthetic-biopart-dismantling-station.png` / `-loop.gif`
  - 폐기된 인공장기 캡슐, 의수·의족 같은 합성 부품을 밀폐된 장치에서 해체합니다.
- `failed-synthetic-human-recovery-capsule.png` / `-loop.gif`
  - 실패한 다운사이징 인공 개체를 빛 입자와 분자로 환원하는 제네시스의 비밀 공정입니다.
- `lysosome-modular-conveyor-straight.png` / `-loop.gif`
  - 장치의 투입구와 배출구를 이어 주는 직선 모듈입니다. PNG는 빈 고정 레일이고 GIF에는 밀폐 폐기물 캡슐이 이동합니다.
- `lysosome-conveyor-curve-left.png` / `-loop.gif`
  - 좌측 방향으로 꺾이는 레일입니다.
- `lysosome-conveyor-curve-right.png` / `-loop.gif`
  - 우측 방향으로 꺾이는 레일입니다.
- `lysosome-conveyor-t-junction.png` / `-loop.gif`
  - 한 개의 이송선을 두 방향으로 나누는 T자 분기 레일입니다.

모든 표현은 피나 상처가 없는 비폭력적 SF 연출이며, 실제 사람이 아니라 인공 부품과 합성 개체만 사용합니다.

## ZEP 사용

- 고정 PNG: 1024×683, 투명 배경
- 움직이는 GIF: 256×171, 6프레임, 무한 반복
- ZEP 에디터의 `나의 오브젝트`에 PNG 또는 GIF를 그대로 업로드합니다.

## 이야기 연결

핵의 설계 → 리보솜의 합성 → 소포체의 가공 → 골지체의 분류·포장 → 라이소솜의 불량품 분해·원료 회수로 이어집니다. 라이소솜 방의 마지막 캡슐은 세포 공장이 다운사이징 인류를 반복 생산하고 실패 개체까지 재활용했다는 사실을 드러내는 단서로 사용할 수 있습니다.
