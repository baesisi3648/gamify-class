# 핵 방 움직이는 오브젝트 세트

기존 핵 방 고정 PNG 5종은 그대로 유지하고, 각 기능을 보여 주는 투명 반복 GIF를 별도 제작한 세트입니다.

## 구성

- `nucleus-command-core-loop.gif` — DNA 홀로그램과 관제 링 맥동
- `dna-genomic-data-archive-loop.gif` — 세 유전체 캡슐의 신호 상승
- `nucleolus-fabrication-core-loop.gif` — 리보솜 소단위체 배출
- `nuclear-pore-gateway-loop.gif` — 핵공 수송 입자와 포털 순환
- `chromatin-data-spool-rack-loop.gif` — 염색질 데이터 빛띠 이동

모든 GIF는 투명 배경, 256×171px, 6프레임, 무한 반복으로 제작했습니다. ZEP의 `나의 오브젝트`에 그대로 업로드하면 별도 앱 없이 재생됩니다.

같은 위치에 고정 PNG와 GIF를 동시에 겹치지 말고 둘 중 하나를 선택해 사용하세요.
