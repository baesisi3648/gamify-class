# 노후 생명·화학 실험실 전용 리보솜 방 설치

이 ZIP은 프로젝트 제네시스의 **노후 생명·화학 실험실 960×640 맵**에 맞춰져 있습니다.

## 적용 순서

1. ZEP 맵 공방에서 `노후 생명·화학 실험실`의 아랫배경과 윗배경을 적용합니다.
2. ZEP 스크립트의 `내 앱`에서 `새 앱 만들기`를 선택합니다.
3. 앱 종류는 `Normal App`으로 선택합니다.
4. `zep-weathered-biolab-ribosome-room-upload.zip`을 업로드합니다.
5. 앱 아이콘이 필요하면 같은 폴더의 `app-icon.png`를 사용합니다.
6. 해당 맵의 앱 설정에서 만든 앱을 활성화한 뒤 테스트합니다.

## 맵 전용 배치

- 조립 설비: 타일 `(10, 8)`
- 컨베이어 3개: 타일 `(5, 14)`, `(11, 14)`, `(17, 14)`
- 아미노산 포드 경로: `(19, 14) → (15, 14) → (11, 14) → (7, 14)`
- 모든 오브젝트는 충돌 없이 배치되므로 학생 이동을 막지 않습니다.
- 앞쪽 난간은 기존 윗배경 레이어가 자연스럽게 가려 줍니다.

다른 크기의 맵에서는 좌표가 맞지 않으므로 일반형 ZIP을 사용하거나 `main.js`의 좌표를 조정해야 합니다.
