# 노후 생명·화학 실험실 전용 리보솜 생산라인 설치

이 ZIP은 프로젝트 제네시스의 **노후 생명·화학 실험실 960×640 맵**에 맞춰져 있습니다.

## 적용 순서

1. ZEP 맵 공방에서 `노후 생명·화학 실험실`의 아랫배경과 윗배경을 적용합니다.
2. ZEP의 `내 앱`에서 새 `Normal App`을 만듭니다.
3. `zep-weathered-biolab-ribosome-room-upload.zip`을 압축 해제하지 않고 업로드합니다.
4. 해당 맵의 앱 설정에서 만든 앱을 활성화한 뒤 테스트합니다.

## 맵 전용 배치

- 좌우 반전된 리보솜 장비: 오른쪽 작업 구역 타일 `(20, 8)`
- 반복 동작 기계팔 2대: 타일 `(17, 9)`, `(23, 9)`
- 남서쪽으로 연결한 컨베이어 3개: 타일 `(10, 14)`, `(15, 12)`, `(20, 10)`
- 아미노산 포드 경로: `(20, 10) → (15, 12) → (10, 14)`
- 모든 오브젝트는 충돌 없이 배치되어 학생 캐릭터 이동을 막지 않습니다.

다른 크기의 맵에서는 좌표가 맞지 않으므로 `main.js`의 좌표를 조정해야 합니다.
