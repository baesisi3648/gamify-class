# ZEP 리보솜 자동 생산 라인 설치

## 가장 빠른 적용 방법

1. `zep-ribosome-factory-upload.zip`과 `app-icon.png`를 내려받습니다.
2. ZEP의 **내 앱 → 앱 업로드**에서 앱 유형을 **Normal App**으로 선택하고 아이콘과 ZIP을 올립니다.
3. 적용할 맵의 편집 화면에서 **맵 설정 → Application**으로 들어가 업로드한 앱을 선택합니다.
4. 맵을 실행하면 리보솜과 레일이 나타나고 아미노산 포드가 자동으로 움직입니다.

ZIP을 다시 압축 해제하거나 내부 폴더째 올리지 마세요. 제공된 ZIP은 `main.js`와 PNG가 최상위에 들어 있는 업로드용 파일입니다.

## 위치 조정

기본 위치가 벽과 겹치면 `main.js` 맨 위의 두 값만 수정한 뒤 다시 압축합니다.

```javascript
const BASE_X = 6;
const BASE_Y = 6;
```

- `BASE_X`: 설비를 좌우로 이동
- `BASE_Y`: 설비를 위아래로 이동

한 칸을 옮길 때 숫자를 1씩 바꿉니다.

## 들어 있는 동작

- E·P·A 스테이션 내부의 포드 반복 애니메이션
- 직선 레일 3개 자동 배치
- 아미노산 포드의 A → P → E → 배출 자동 이동
- 마지막 지점 도착 후 역방향 자동 운행
- 앱 실행 시 자동 시작
