🌴 애니멀 트랩 사용 안내

8팀이 16×16 초원에서 서로 숨긴 덫을 피해 가운데 오아시스로 달리는 실시간 퀴즈 게임입니다. 덫을 밟으면 문제를 풀고, 맞히면 덫을 걷어 냅니다.

교사 화면문제은행학생 입장
준비문제 넣기판 만들기·입장진행 순서규칙문제 생기면문제 파일 형식

1. 준비물

  • 교사 컴퓨터 1대 — 교사 화면(진행 버튼, 팀 현황).
  • TV·프로젝터 — 교사 화면의 'TV 화면 열기'로 띄운 창. 보드·시계·점수만 보이고 덫은 보이지 않습니다.
  • 팀마다 폰·태블릿 1대 이상(8팀). 팀에서 처음 들어온 기기가 조작하고, 나머지 기기는 보기만 합니다.
  • 수업 시간: 설명 5분 + 덫 설치 2분 + 게임 15분 + 복습 5~10분 정도(기본값 기준).

2. 수업 전: 문제 넣기

  1. 문제은행에서 관리자 비밀번호로 들어갑니다.
  2. 문제 파일(JSON)을 고르거나 붙여넣고 미리보기 → 가져오기. 애니멀 더비에서 내보낸 파일을 그대로 쓸 수 있고, '빈 양식 받기'로 양식을 받을 수 있습니다.
  3. 세트마다 쉬움·보통·어려움이 각각 1문항 이상 있어야 판을 만들 수 있습니다. 15분 판이면 난이도별 12문항 이상을 권합니다(적으면 같은 팀이 같은 문제를 다시 받을 수 있어요).
  4. 한 세트는 300문항까지. 고치기 전에는 '내보내기'로 파일을 받아 백업해 두세요.

3. 판 만들기와 학생 입장

  1. 교사 화면에서 판 제목·문제 세트(비우면 전체 문제은행)·시간을 정하고 관리자 비밀번호로 판 만들기.
  2. 판 코드(6글자)와 팀별 QR·PIN 카드가 나옵니다. '인쇄'로 팀에 나눠 주거나 TV에 보여 줍니다.
  3. 학생은 QR을 찍거나 학생 입장 주소에서 판 코드 → 팀 → PIN(4자리)을 넣습니다.
  4. 교사 화면 팀 표에서 8팀이 모두 접속했는지 확인합니다.

교사 열쇠는 판을 만든 브라우저에만 저장됩니다. 그 브라우저의 '이어하기'로 다시 들어갈 수 있고, 다른 컴퓨터에서는 이어할 수 없어요. 공용 컴퓨터라면 수업 뒤 '판 기록 지우기'를 눌러 주세요.

4. 진행 순서 (교사 버튼)

  1. 추첨 — 8팀의 출발 구역(가장자리 8곳)을 무작위로 정합니다.
  2. 덫 설치 시작 — 팀마다 덫 13개(일반 10·귀환 1·속박 1·혼란 1)가 자동으로 놓입니다. 정해진 시간(기본 2분) 안에 폰에서 덫을 옮기거나 두 덫 자리를 바꾸고 확정합니다. 전원 확정하거나 '지금 마감'을 누르면 끝납니다.
  3. 게임 시작 — 메인 시계(기본 15분)가 흐릅니다. 한 라운드는:
    • 이동(기본 20초): 주변 8칸 중 한 칸을 고르고 ‘이 칸으로 이동하기’를 눌러야 제출됩니다. 고르기만 하고 누르지 않으면 제자리.
    • 문제(기본 45초): 덫 칸에 내린 팀만. 시간 안에 안 내면 오답.
    • 결과: 점수·덫 제거·특수 효과 표시 → 교사가 다음 라운드(또는 '5초 뒤 자동' 설정).
  4. 메인 시계가 끝나는 순간 이동 중이던 라운드는 취소되고 바로 종료됩니다. 이미 문제를 풀고 있던 라운드는 문제 시간이 끝날 때까지 마저 풀고 점수를 반영한 뒤 종료됩니다. '종료' 버튼을 누르면 그 순간 마감 전 라운드는 취소됩니다.
  5. 복습 — 순위 발표, 덫 지도 공개, 사용된 문제의 정답·해설을 하나씩 TV에 띄웁니다.

'일시정지'를 누르면 메인 시계와 단계 시계가 모두 멈춥니다. 학생 질문을 받거나 설명할 때 쓰세요.

5. 규칙 요약 (학생 설명용)

목표: 시간이 끝났을 때 점수가 가장 높은 팀이 우승. 오아시스에 먼저 닿을수록 큰 점수지만, 가는 길에 다른 팀의 덫이 숨어 있습니다.

상황점수
덫이 없는 새 칸에 처음 도착+1
다른 팀 출발 구역에 처음 도착+10
덫 칸에서 문제 정답 (덫 n개: 1개 쉬움·2개 보통·3개 이상 어려움)+(n+2)
덫 칸에서 오답·시간 초과−(n+1)
오아시스 도착 1위 / 2위 / 3위 이후 (같은 라운드 도착은 공동 순위)+30 / +20 / +15

덫과 특수 효과

  • 문제를 맞히면 그 칸의 덫이 모두 사라집니다. 같은 칸에 여러 팀 덫이 겹쳐 있을 수 있어요.
  • 틀리면 그 칸 특수 덫 중 가장 강한 하나가 발동: 귀환(출발 칸으로) > 속박(다음 2라운드 이동 불가) > 혼란(다음 2라운드 센서 끔).
  • 센서: 폰에 지금 칸 주변 8칸의 덫 개수가 보입니다(우리 팀 덫 포함). 숫자를 보고 길을 고르세요.
  • 정찰권: 오아시스에 도착하면 1회. 원하는 3×3 구역의 상대 덫 위치를 봅니다.
  • 같은 점수는 같은 순위입니다(공동 우승 가능).

6. 문제가 생기면

폰 연결이 끊겼어요
화면 위에 '연결이 끊겼어요' 띠가 뜨고 저절로 다시 붙습니다. 새로 고쳐도 같은 기기면 조작이 그대로 유지돼요. 서버가 다시 시작돼도 판은 그대로 이어집니다.
조작하던 폰이 꺼져서 다른 폰으로 조작하고 싶어요
교사 화면 '팀 접속 관리' → 그 팀 조작권 해제. 그다음 새 기기로 다시 입장하면 그 기기가 조작합니다.
PIN을 여러 번 틀려 잠겼어요
5번 틀리면 30초 잠깁니다. 교사가 '잠금 해제'를 누르거나, PIN이 새어 나갔다면 'PIN 재발급'(그 팀 기기는 새 PIN으로 다시 입장).
TV 화면 주소가 학생에게 퍼졌어요
TV 화면은 보기 전용이라 조작은 못 하지만, 'TV 열쇠 재발급'을 누르면 예전 주소는 바로 끊깁니다. 새 TV 화면을 다시 여세요.
이동을 못 했어요
시간 안에 안 고르면 제자리입니다. 속박에 걸린 팀은 2라운드 동안 움직일 수 없어요.
판을 만들 수 없다고 나와요
세트에 쉬움·보통·어려움이 각 1문항 이상인지 문제은행에서 확인하세요(빨간 칸이 0개인 난이도).

7. 문제 파일 형식

애니멀 더비와 같은 JSON 형식입니다. difficulty는 easy·medium·hard(또는 쉬움·보통·어려움), answer는 정답 보기 번호(1~4), explanation은 비워도 됩니다. 보기는 꼭 4개, 문제는 500자·보기는 150자·해설은 1000자까지.

{
  "title": "효소 단원",
  "questions": [
    {
      "difficulty": "easy",
      "question": "효소의 주성분은?",
      "choices": ["탄수화물", "단백질", "지방", "핵산"],
      "answer": 2,
      "explanation": "효소는 대부분 단백질로 이루어져 있다."
    }
  ]
}

형식이 틀린 문항은 가져오기 미리보기에서 '몇 번째 문항이 왜' 틀렸는지 알려 주고 건너뜁니다.
