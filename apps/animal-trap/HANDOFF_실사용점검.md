## 3. 수업하면서 눈여겨볼 것

**규칙·밸런스** (시뮬레이션 기준으로 정해 둔 값 — 실제 반응을 보고 조정 예정)
- 15분 동안 라운드가 몇 번 도는지, 팀당 문제를 몇 번 받는지 (시뮬레이션: 팀당 약 4~5문제)
- **보통·어려움 문제가 실제로 나오는지** (덫이 2개·3개 이상 겹친 칸에서만 나옴)
- 오아시스로 곧장 달리는 전략만 이기는지 (시뮬레이션에서 그런 경향이 있었음 — 오아시스 30/20/15점)
- 덫 설치 2분이 충분한지/긴지, 이동 20초·문제 45초가 적당한지
- 학생들이 **센서 숫자(주변 덫 개수)** 를 이해하고 쓰는지, 정찰권을 쓰는지

**화면·조작**
- 학생이 칸만 고르고 **‘이 칸으로 이동하기’를 안 눌러** 제자리에 남는 일이 잦은지
- 팀에서 두 번째로 들어온 폰은 **보기 전용**인 것을 학생들이 이해하는지
- 교사가 진행 버튼(‘지금 마감’, ‘다음 라운드’)을 찾기 쉬운지, 5초 자동 넘김이 나은지
- TV에서 지금 무슨 단계인지 뒤에서도 알아보는지

**운영**
- 접속이 끊겨 ‘연결이 끊겼어요’ 띠가 자주 뜨는지, 응답이 느린 순간이 있는지
- 조작권 해제·PIN 재발급·잠금 해제를 실제로 쓸 일이 있었는지

## 4. 고칠 점 남기는 법

아래 틀로 적어 주면 그대로 고칠 수 있습니다. 화면 사진(스크린샷)이 있으면 가장 좋습니다.

```
- 어느 화면: (팀 폰 / 교사 / TV / 문제은행 / 사용 안내)
- 언제: (예: 2라운드 문제 풀이 중, 덫 설치 중)
- 무엇이: (예: 정답 버튼이 화면 밖으로 밀려남)
- 기대: (예: 스크롤 없이 4개 보기가 다 보여야 함)
- 기기: (예: 갤럭시 S21, 크롬 / 교실 TV 4:3)
- 판 코드: (있으면. 예: NM4A47)
- 얼마나 급한지: (수업 불가 / 불편 / 있으면 좋음)
```

규칙을 바꾸고 싶다면 "왜"를 같이 적어 주세요(예: "어려움 문제가 한 번도 안 나와서 덫 2개부터 어려움으로").

## 6. 고친 뒤 확인·배포 (apps/animal-trap 폴더에서)

```bash
npm test                 # 타입 검사 + 단위 테스트 88개
npm run e2e:faults       # 실제 서버를 띄워 장애 상황 검사(재시작 복원·시간 초과·소켓 한도 등, 약 2분)
npm run deploy           # 테스트 → 빌드 → Cloudflare 배포 (계정 baesisi3648)
```

- 전체 한 판 E2E: `npx wrangler dev --local --port 8789 --var ADMIN_PASSWORD:아무값` 을 띄운 뒤
  `BASE=http://localhost:8789 ADMIN_PASSWORD=아무값 node scripts/e2e.ts` (로컬 D1 에 `scripts/e2e-seed.sql` 의 'E2E' 세트 필요)
- 메인 페이지 카드는 저장소 루트 `apps/index.html` 의 `id: "animal-trap"` 항목. main 에 push 하면 gamifyclass.pages.dev 에 반영됩니다.
- 배포는 진행 중인 판을 끊지 않도록 **수업 시간 밖에** 하세요(배포 순간 소켓이 다시 연결됩니다. 판 상태는 보존).

## 7. 알아 두면 좋은 동작 (버그 아님)

- **교사 열쇠는 판을 만든 브라우저에만** 저장됩니다. 다른 컴퓨터에서는 그 판을 이어 진행할 수 없습니다.
- **메인 시간이 끝나면**: 이동 중이던 라운드는 취소되고 바로 종료, 문제를 풀던 라운드는 마저 정산 후 종료.
- **이동을 안 누르면 제자리**, 문제를 안 내면 **오답**(감점).
- **자기 팀 덫도 자기에게 발동**합니다(센서 숫자에도 포함).
- **소켓 자리**: 한 판에 교사 4 · TV 4 · 팀당 7개. 넘치면 같은 칸의 가장 오래된 화면이 끊기고 “새로 고치면 다시 연결돼요”가 뜹니다.
- **PIN 5번 틀리면 30초 잠김.** 교사 화면 ‘팀 접속 관리’에서 잠금 해제.
- **문제은행 세트 이름을 비우고** 판을 만들면 모든 세트를 섞어 쓰고, 300문항이 넘으면 난이도 비율대로 무작위 300문항을 고릅니다.
- 판을 만들 때 문제를 **복사해 고정**하므로, 판 진행 중 문제은행을 고쳐도 그 판에는 영향이 없습니다.
