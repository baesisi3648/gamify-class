# ECO QUEST — 우리 마을 생태지도

수업 코드로 참여하는 생태 조사·개인 생물도감 서비스의 인터랙티브 화면 초안입니다.
현재 버전은 정적 HTML/CSS/JavaScript와 샘플 데이터로 구성되어 있습니다. 카카오 지도는
용인삼계고등학교를 중심으로 연결했으며, 실제 로그인, 관찰 핀 저장, 사진 저장, AI 동정,
D1/R2, Google Sheets 동기화는 아직 연결하지 않았습니다.

## 초안에서 확인할 수 있는 화면

- 수업 코드 학생 로그인과 교사 화면 미리보기
- 통합 및 1~9반 지도 탭, 생물 분류 필터, 군집 핀
- 공동 관찰 사진 1~3장 선택과 대표 사진 지정
- 사진·특징 분석 후 생물 후보 3개 제시 흐름
- 학생 조사 근거와 참고 자료 작성
- 개인 생물도감 기본 3개, 학생 선택으로 최대 5개 확장
- 전체 학급 현황과 예외 검토, Google Sheets 동기화 관리자 초안

모둠 계획서는 첫 수업에서 종이로 진행하므로 사이트 기능에 포함하지 않습니다.
