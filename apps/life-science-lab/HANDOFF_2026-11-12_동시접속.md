## 2. 무엇을 바꿨나

### 동시접속·속도
- **로그인 왕복 1회**: 새 시스템 전용 액션 `auth.login`이 (제한 카운터 → 학생/그룹 조회 → 세션 정보)를 한 번에 처리. 비밀번호 검증은 여전히 Worker가 하고, 검증 성공 시에만 응답을 돌려줌. 브라우저가 보낸 값은 허용 필드(`groupId, role, year, grade, classNo, number, name`)만 전달.
- **읽기 요청은 잠금 없이 처리**: `bootstrap, archive, groups.list, me, myReports, report.meta, students.list, assessments.list, reports.list, publications.list, auth.group, auth.lookup`, 그리고 쓰기가 없는 `auth.login`. 저장·PIN 등록·명단 등록 등 쓰기는 기존처럼 잠금 유지(대기 20초 → 15초).
- **공개 목록 60초 캐시**: `bootstrap / archive / groups.list`는 CacheService에 60초 캐시. 탐구 저장·그룹 변경·전시 공개/취소 시 시트 반영(flush) **후** 캐시 세대를 갱신해서 즉시 새 내용이 보임. 캐시 저장 실패는 조회에 영향 없음.
- **로그인 제한을 Cloudflare로 이동**: `wrangler.jsonc`에 Rate Limiting 바인딩 2개 추가(IP 60초 300회, 학생별 60초 10회). 이 바인딩이 있으면 Sheets에 카운터를 쓰지 않음. 바인딩이 없으면 예전처럼 Sheets 카운터를 쓰되 같은 요청 안에서 처리하고 IP 한도는 600으로 완화.
- **쌓인 카운터 정리 함수** `labPruneRateRows()`: 만료된 `rate:` 행만 아래에서부터 삭제(그룹 설정 등 다른 행은 건드리지 않음).
- **사진 권한 확인**: 보고서 목록 전체 대신 `report.meta`(보고서 1건 소유권만 확인).
- **자동저장**: 입력 멈춤 4초 후 저장(계속 입력 중이어도 최대 20초마다 저장). 재시도는 일시 오류(네트워크·429·5xx)만, 5→10→20→40초에 ±30% 무작위 지연. 400/401/403 같은 오류는 재시도하지 않음.

### 첫 PIN 등록 단순화 (요청 사항)
- 로그인 화면의 **"처음 접속: PIN 등록" 버튼을 없앰**.
- PIN이 없는 학생(명단 등록 시 코드 미지정)이 **일반 로그인 칸에 숫자 4자리를 입력하면 그 숫자가 PIN으로 등록**되고 바로 입장. 입장 후 "방금 입력한 숫자 4자리가 PIN으로 등록되었습니다" 안내.
- PIN이 없는 학생이 4자리 숫자가 아닌 값을 넣으면 "처음 접속이면 앞으로 사용할 숫자 4자리 PIN을 입력하세요" 안내(400).
- 이미 PIN이 있는 학생은 기존과 동일. 교사의 "학생이 PIN을 다시 정하도록"(PIN 해제) 기능도 그대로 동작하며, 해제된 학생은 다음 로그인 때 입력한 4자리가 새 PIN이 됨.
- 주의: 예전처럼 **명단 정보(학년·반·번호·이름)를 아는 사람이 먼저 로그인하면 그 사람이 PIN을 정하게 됨**(기존 "PIN 등록" 버튼도 같은 성질). 첫 수업 때 본인이 직접 입력하도록 안내해 주세요. 잘못 등록되면 교사 관리실 → 학생 명단 → PIN 관리에서 재설정.

## 4. 확인이 필요한 것 (로그를 못 봐서 확정 못 한 부분)
- **Worker CPU 한도**: 비밀번호 해시(PBKDF2 10만 회)는 CPU를 많이 씁니다. Workers **무료 플랜**이면 동시 로그인 때 `Exceeded CPU time limit`(오류 1102)가 날 수 있습니다. `wrangler tail`에서 이 오류가 보이면 Workers Paid(월 $5)를 검토하세요. 해시 방식은 기존 PIN이 무효화되므로 바꾸지 않았습니다.
- Apps Script 실행 기록에 `Service invoked too many times`, `동시 실행` 관련 오류가 있었는지.
- `Settings` 탭 행이 얼마나 쌓여 있었는지(많았다면 느림의 큰 원인이었음).

## 5. 되돌리기 (3-0-1에서 메모한 번호 사용)
